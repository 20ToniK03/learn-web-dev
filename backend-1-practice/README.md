# Задание 1. Класс Appointment

Учебный проект салона красоты на Python. Запись клиента вынесена в класс `Appointment`, добавлено правило рабочих часов.

## Что работает

- `create_appointment` возвращает объект класса `Appointment`;
- запись создаётся только при заполненных полях и существующих мастере и услуге;
- запись возможна только с 08:00 до 20:00;
- некорректная запись не попадает в список `appointments`.

## Запуск

```
python main.py
```

## Структура

- `main.py` - класс `Appointment`, данные и демонстрация.

## Технологии

Python 3.14, стандартная библиотека.
