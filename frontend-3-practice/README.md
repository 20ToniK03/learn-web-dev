# Задание 3. Основы React

Страница записи в салон красоты «Стрижки экспресс», переведённая с HTML и нативного JavaScript на React.

## Запуск

```
npm install
npm run dev
```

Откройте адрес, который напишет Vite.

## Что работает

- календарь строится через JSX и `.map()`;
- переключение месяцев стрелками;
- выбор дня и времени через `useState`;
- прошлые дни недоступны;
- сегодняшний и завтрашний дни отмечены как занятые;
- занятые слоты отмечены и недоступны;
- при смене дня выбранное время сбрасывается;
- нижняя панель показывает день недели, число, месяц, год и выбранное время.

## Структура

- `src/main.jsx` - точка входа;
- `src/App.jsx` - сборка страницы;
- `src/screens/BookingScreen.jsx` - состояние и обработчики;
- `src/components/booking/` - компоненты календаря, слотов и нижней панели;
- `src/data/date.js` - функции для работы с датами;
- `src/data/slots.js` - данные слотов и времени;
- `src/index.css` - стили страницы.

## Технологии

React, Vite, JSX, CSS.
