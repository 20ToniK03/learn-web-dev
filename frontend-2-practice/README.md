# Задание 2. JavaScript

Интерактивная страница записи в салон красоты «Стрижки экспресс».

## Что работает

- календарь строится через JavaScript;
- переключение месяцев стрелками;
- выбор дня и времени;
- прошлые дни, месяцы и годы недоступны;
- стрелка «назад» блокируется на текущем месяце;
- сегодняшний и завтрашний дни отмечены как занятые и недоступны;
- занятые слоты отмечены и недоступны;
- при смене дня выбранное время сбрасывается;
- нижняя панель обновляется автоматически;
- кнопка «Продолжить» активна только после выбора даты и времени.

## Текущая дата

«Сегодня» определяется через `new Date()`, поэтому прошлые дни блокируются автоматически. Сегодняшний и завтрашний дни всегда отмечены как занятые, календарь открывается на ближайшем свободном дне. Расписание свободных слотов формируется случайно при загрузке страницы.

## Страницы

- `index.html` - выбор даты и времени;
- `contacts.html` - контактные данные;
- `review.html` - проверка записи;
- `success.html` - подтверждение записи.

## Запуск

Откройте `index.html` в браузере.

## Технологии

HTML5, CSS3 и JavaScript без библиотек.
