# Задание 4. Асинхронный Javascript и создание React-приложений

Страница записи в салон красоты «Стрижки экспресс» на React с имитационным сервером.

## Запуск

```
npm install
npm run dev
```

Vite откроет адрес страницы, сервер запустится на http://localhost:3000.

## Что работает

- при открытии страницы загружаются «сегодня» и слоты с сервера;
- при клике по дню загружаются слоты выбранного дня;
- при смене дня выбранное время сбрасывается;
- во время загрузки показывается состояние loading;
- при ошибке сервера показывается сообщение;
- прошлые дни недоступны;
- стрелки листают месяцы;
- нижняя панель показывает дату и время.

## API

- GET /api/booking/today - возвращает `{ day, month, year }`;
- GET /api/slots?day=&month=&year= - возвращает `{ date, slots }`.

## Структура

- `server/server.js` - имитационный сервер;
- `server/database.js` - данные о «сегодня» и слотах;
- `src/api.js` - запросы `fetchToday()` и `fetchSlots(date)`;
- `src/screens/BookingScreen.jsx` - состояние и загрузка данных;
- `src/components/booking/` - компоненты страницы.

## Технологии

React, Vite, Express, JSX, CSS.
