# Задание 1. HTML/CSS

Прототип записи в салон красоты «Стрижки экспресс».

## Страницы

- `index.html` - выбор даты и времени;
- `contacts.html` - контактные данные;
- `review.html` - проверка записи;
- `success.html` - подтверждение записи.

## Запуск

Откройте `index.html` в браузере.

## Технологии

HTML5 и CSS3. Без JavaScript.
