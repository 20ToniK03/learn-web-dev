# Тестирование. Задание 2. Тестовая документация

Объект тестирования: учебное приложение салона ÉLAIRE (React + Vite, имитационный сервер).
Документ содержит чек-лист шага «Выбор услуги», два тест-кейса, баг-репорт по полю телефона и Use Case сценария записи.

## 2.1. Чек-лист и тест-кейсы

### Тест-кейс TC-01. Успешная запись на услугу через весь сценарий

| Поле | Значение |
|---|---|
| ID | TC-01 |
| Название | Успешная запись на услугу через весь сценарий |
| Предусловия | Dev-сервер запущен по адресу http://localhost:3000. Файл server/bookings.txt пуст или не содержит тестовых записей. Сервер считает сегодняшней датой 17 октября 2026. В категории «Маникюр и педикюр» есть услуга «Японский эстетический маникюр P.Shine». |
| Шаги | 1. Открыть главную страницу.<br>2. Нажать «Записаться на услугу».<br>3. Дождаться загрузки категорий.<br>4. Выбрать категорию «Маникюр и педикюр».<br>5. Нажать «Выбрать» у услуги «Японский эстетический маникюр P.Shine».<br>6. Дождаться загрузки календаря и слотов.<br>7. Выбрать день 17 октября 2026.<br>8. Выбрать время 12:00.<br>9. Нажать «Далее».<br>10. Ввести имя «Анна Петрова».<br>11. Ввести телефон «+7 (999) 123-45-67».<br>12. Нажать «Подтвердить запись». |
| Ожидаемый результат | Открывается модальное окно «Запись подтверждена». В окне указаны услуга «Японский эстетический маникюр P.Shine», дата и время «17 октября 2026, 12:00», мастер, длительность 50 мин и цена 3 200 ₽. Запись сохранена на сервере в server/bookings.txt с полями serviceId, date, time, name, phone, comment. После нажатия «Отлично!» приложение возвращается на главную, данные записи сбрасываются. |

| Поле | Значение |
|---|---|

| Название | Попытка подтвердить запись с пустым номером телефона |

## 2.2. Баг-репорт по полю «Номер телефона»

### BUG-01. Поле «Номер телефона» принимает некорректные данные и не поддерживает формат +7

| Поле | Значение |
|---|---|
| ID | BUG-01 |
| Заголовок | Поле «Номер телефона» на шаге 3 принимает буквы и любые символы, не поддерживает ввод «+7», запись подтверждается с некорректным номером |
| Компонент | Экран «Подтверждение записи», блок «Контактные данные», поле «Номер телефона» |
| Серьёзность | Высокая (High) |
| Приоритет | Высокий (P1) |
| Окружение | Windows 11 Pro 26200, Microsoft Edge 157.0.4341.46, Google Chrome 157.0.8103.52, разрешение 1440x1000, Node.js 22.22.2, Vite 8.2.1, dev-сервер http://localhost:3000 |
| Предусловия | Приложение запущено. Пользователь прошёл шаги 1 и 2: выбрал услугу, дату и время, открыл экран «Подтверждение записи». Поле «Ваше имя» заполнено. |
| Шаги воспроизведения | 1. Открыть главную страницу и нажать «Записаться на услугу».<br>2. Выбрать категорию «Маникюр и педикюр» и услугу «Японский эстетический маникюр P.Shine».<br>3. Выбрать день 17 октября 2026 и время 12:00, нажать «Далее».<br>4. В поле «Ваше имя» ввести «Анна Петрова».<br>5. В поле «Номер телефона» ввести «abc-XYZ!@#».<br>6. Нажать «Подтвердить запись».<br>7. Повторить шаги 1-4, ввести в поле телефона «+7», нажать «Подтвердить запись».<br>8. Повторить шаги 1-4, оставить поле телефона пустым, нажать «Подтвердить запись».<br>9. Проверить server/bookings.txt. |
| Ожидаемый результат | Поле принимает только цифры и символы форматирования номера. Буквы и посторонние символы не вводятся или блокируются при проверке. Номер «+7 (999) 123-45-67» вводится и распознаётся как корректный. Пустой или некорректный номер не позволяет отправить форму: под полем появляется сообщение об ошибке, модальное окно не открывается, запись на сервер не уходит. |
| Фактический результат | Поле принимает буквы, пробелы и специальные символы: значение «abc-XYZ!@#» отображается в поле без ограничений. Маска и проверка формата отсутствуют. Форма отправляется с пустым, коротким, длинным или неверным номером. Модальное окно «Запись подтверждена» открывается, в server/bookings.txt сохраняется запись с phone: "" или phone: "abc-XYZ!@#". Ввод «+7» в desktop-браузере проходит, но номер не форматируется и не проверяется; на мобильных устройствах поведение ввода «+7» требует отдельной проверки. |
| Дополнительные данные | Скриншот 1: экран «Подтверждение записи», поле «Номер телефона» обведено красной рамкой, в поле введено «abc-XYZ!@#». Скриншот 2: модальное окно «Запись подтверждена» после отправки формы с пустым телефоном. Скриншот 3: фрагмент server/bookings.txt со строкой, где phone пустой. Лог сервера: «Запись сохранена: { ... phone: "" }». Версия браузера и ОС указаны в поле «Окружение». |
| Обоснование серьёзности и приоритета | Серьёзность высокая: дефект находится в основном сценарии записи и приводит к сохранению недостоверных контактных данных, из-за чего салон не может связаться с клиентом. Приоритет P1: без проверки телефона подтверждение записи теряет практический смысл, а все заявки требуют ручной проверки, поэтому исправление нужно до релиза. |

## 2.3. Use Case: клиент записывается на услугу

### UC-01. Запись клиента на услугу

| Поле | Значение |
|---|---|
| Название | Запись клиента на услугу |
| Актор | Клиент |
| Цель | Оформить запись на услугу в салоне ÉLAIRE |
| Предусловия | Приложение доступно, имитационный сервер отвечает, у клиента есть доступ к сайту |
| Постусловия | Запись сохранена на сервере, клиент увидел подтверждение и вернулся на главную |
| Основной сценарий | 1. Клиент открывает главную страницу.<br>2. Клиент нажимает «Записаться на услугу».<br>3. Система загружает категории и показывает экран «Выбор услуги».<br>4. Клиент выбирает категорию.<br>5. Система показывает услуги выбранной категории.<br>6. Клиент нажимает «Выбрать» у нужной услуги.<br>7. Система открывает экран «Выбор даты и времени» и загружает календарь.<br>8. Клиент выбирает доступный день.<br>9. Система загружает слоты на выбранный день.<br>10. Клиент выбирает доступное время и нажимает «Далее».<br>11. Система открывает экран «Подтверждение записи» и показывает детали визита.<br>12. Клиент заполняет имя и телефон, при необходимости добавляет комментарий.<br>13. Клиент нажимает «Подтвердить запись».<br>14. Система отправляет запись на сервер.<br>15. Система показывает модальное окно «Запись подтверждена».<br>16. Клиент нажимает «Отлично!».<br>17. Система возвращает клиента на главную и сбрасывает данные записи. |
| Точка ветвления | Шаг 4: клиент может выбрать услугу или мастера. В текущей версии реализован только выбор услуги. Кнопка «Выбрать мастера» на главной есть, но не открывает выбор мастера, а мастер в деталях визита всегда один и тот же. Поэтому ветка «выбор мастера» описана отдельным Use Case UC-02 и пока не реализована. |

### UC-02. Запись клиента к конкретному мастеру

| Поле | Значение |
|---|---|
| Название | Запись клиента к конкретному мастеру |
| Актор | Клиент |
| Цель | Выбрать мастера и записаться на его услугу |
| Предусловия | Приложение доступно, список мастеров загружен |
| Постусловия | Запись сохранена с выбранным мастером, клиент увидел подтверждение |
| Основной сценарий | 1. Клиент открывает главную страницу.<br>2. Клиент нажимает «Выбрать мастера».<br>3. Система показывает список мастеров с именем, специализацией и рейтингом.<br>4. Клиент выбирает мастера.<br>5. Система показывает услуги выбранного мастера.<br>6. Клиент выбирает услугу.<br>7. Система открывает выбор даты и времени с учётом расписания мастера.<br>8. Клиент выбирает день и время.<br>9. Система открывает подтверждение и показывает выбранного мастера.<br>10. Клиент заполняет контакты и подтверждает запись.<br>11. Система сохраняет запись с masterId выбранного мастера и показывает подтверждение. |
| Статус | Не реализовано. Кнопка «Выбрать мастера» не имеет обработчика, masterId в запись не передаётся, в деталях визита мастер захардкожен. |

### Расширения и негативные сценарии

| ID | Условие | Действие системы |
|---|---|---|
| E1 | Категории не загрузились | Показать сообщение «Ошибка: ...», оставить кнопку «Назад» |
| E2 | В категории нет услуг | Показать заглушку пустого списка, не открывать выбор даты |
| E3 | Услуги не загрузились | Показать сообщение об ошибке, не открывать выбор даты |
| E4 | На выбранный день нет свободных слотов | Показать «В этот день нет доступного времени», не разрешать переход дальше |
| E5 | Клиент нажал «Далее» без времени | Показать предупреждение «Пожалуйста, выберите время», остаться на экране |
| E6 | Клиент вернулся с подтверждения назад | Вернуть на выбор даты и времени, сохранить выбранные услугу, дату и время |
| E7 | Имя не заполнено или не соответствует требованиям | Показать ошибку под полем, не отправлять форму |
| E8 | Телефон не заполнен или не соответствует формату | Показать ошибку под полем, не отправлять форму |
| E9 | Сервер не сохранил запись | Показать сообщение об ошибке, оставить форму заполненной |
| E10 | Слот уже занят другим клиентом | Показать сообщение о занятости слота и предложить выбрать другое время |
| E11 | Клиент закрыл модальное окно подтверждения | Вернуть на главную и сбросить данные записи |
| E12 | Клиент нажал «Назад» на экране выбора услуги | Вернуть на главную |
